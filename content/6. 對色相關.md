## 6-1 分光儀

### 測色原理

1. **光源照射樣品**
   - 儀器以標準光源照射布料表面。
2. **樣品反射光線**
   - 布料吸收部分光線，並反射不同波長的光。
3. **分光量測**
   - 分光元件將反射光分解成不同波長，感測器量測各波長的反射率。
4. **數據運算**
   - 電腦根據反射光譜計算出 **L\*、a\*、b\*** 等色彩數據。
5. **色差分析**
   - 與標準色比較，計算 **ΔL、Δa、Δb、ΔE**，判斷顏色是否符合要求。

### 紡織染整常用光源

- **D65**：標準對色光源，也是大多數紡織規範的預設光源。
- **TL84（F11）**：模擬百貨公司、服飾店照明。
- **A**：模擬居家黃光，檢查暖光下是否偏色。
- **CWF（Cool White Fluorescent，通常接近 F2）**：模擬冷白螢光燈環境

### 測色手法

黏扣帶對色以帶面為主，測色需確認預覽畫面中測色區無汙點、毛屑。
單片試樣測4次，每測完一次換不同位置轉90度方向再測。
注意清潔測量孔，注意不可直接接觸積分球或分光儀內部，以吹球吹掉灰塵即可。
### 主要判色數值
| 順序       | 看什麼 | 判斷內容                 |
| -------- | --- | -------------------- |
| **ΔE**   | 總色差 | 是否在允收範圍內。            |
| **ΔL***  | 深淺  | + 偏淺；− 偏深。           |
| **Δa***  | 紅／綠 | + 偏紅；− 偏綠。           |
| ** Δb*** | 黃／藍 | + 偏黃；− 偏藍。           |
| **ΔC***  | 彩度  | + 鮮豔；− 灰暗。           |
| **ΔH***  | 色相  | 確認色相偏移是否由 a*、b*共同造成。 |
## ΔE（色差）★★★★★

最主要的指標，代表樣品與標準色的整體差異。
但即便ΔE 值低，需再確認色相是否在同一象限。

一般標準

| ΔE      | 判定      |
| ------- | ------- |
| <0.3    | 幾乎看不出差異 |
| 0.3~0.5 | 非常好     |
| 0.5~0.8 | 良好      |
| 0.8~1.0 | 一般客戶可接受 |
| >1.0    | 容易看出色差  |
| >1.5    | 多半NG    |
