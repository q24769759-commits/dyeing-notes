# 2. 助劑相關

## 2-1. 酸劑

- 控制浴液 pH，影響染料與纖維的電荷關係
- pH 過低 → 染料上色過快 → **色花**
- pH 過高 → 染料上色不足 → **顏色偏淺、殘液多**
- 染色過程需配合升溫程序設計酸劑加入時機

### PHS（pH 滑動劑）

染色前加入，pH 值隨溫度上升緩慢下降，避免一開始酸度太高造成染料快速上色而產生色花。
實驗室試驗 軟水加PHS 於燒杯加熱，每5度紀錄pH值 加熱至沸騰在持續15分鐘。
![[Pasted image 20260715083037.png]]

### SA 硫酸銨 (NH₄)₂SO₄

硫酸銨特性隨溫度上升緩釋酸，因此適合在染前加入，染程升溫時隨著溫度升高 pH 下降，但有水質氨氮問題，不適合長期大量使用。
實驗室試驗 軟水加SA 於燒杯加熱，每5度紀錄pH值 加熱至沸騰在持續15分鐘。

### HAC 冰醋酸 

pH 下降快速，用於染程後段殘液吸收用，注意加酸手法需少量慢速，避免 pH 下降過快導致色花，加完酸後須再高溫（100 度）持溫約 30min 使染料均勻穩定。


### 醋酸鈉（常搭配冰醋酸）

本身溶於水呈微鹼性，與冰醋酸形成緩衝，可使染程 pH 變化更平緩。

## 2-2. 均染劑

### 親染料均染劑 vs 親纖維均染劑

| 項目     | 親染料均染劑（Dye Affinitive） | 親纖維均染劑（Fiber Affinitive） |
| ------ | ---------------------- | ------------------------ |
| 作用對象   | 染料                     | 纖維                       |
| 作用機制   | 暫時與染料結合，降低自由染料濃度       | 暫時占據纖維染座，降低染料吸附速度        |
| 染色初期   | 控制染料活性                 | 控制纖維活性                   |
| 延緩上色效果 | 中等                     | 較強                       |
| 移染能力   | 較佳                     | 一般                       |
| 修正色花能力 | 優秀                     | 普通                       |
| 預防色花能力 | 良好                     | 優秀                       |
| 對尼龍適用性 | 良好                     | 非常適合                     |
| 對深色染色  | 適合                     | 適合                       |
| 對淺中色染色 | 適合                     | 特別適合                     |
| 用量過多風險 | 吸盡率下降、殘液較高             | 上色不足、染程變長                |
| 主要用途   | 提高移染性、修正色花             | 防止搶色、預防色花                |

## 2-3. 其他助劑

### 固色劑

- **後處理步驟（染色完成後使用）**
- 在纖維表面形成保護膜，提升水洗牢度與摩擦牢度
- 注意：固色劑可能輕微影響色相（偏黃或偏紅），手感偏硬
- 原理：酸性染料的 SO3⁻ 與尼龍纖維的 NH3⁺ 離子鍵結合，當染深色時加入固色劑再使之吸附到纖維表面，把染料包覆住，形成第二層固定。

![[Pasted image 20260710140134.png|539]]

**N40A（含雙酚 S） - 勝暉**
主成分：4,4'-二羥基二苯碸（雙酚 S）－甲醛－硫酸聚合物（36-44%）　CAS NO. 41311-58-4
物性：深褐色，原液 pH 3 ± 0.5。
用法用量：深色染程結束排水 → 入冷水洗 → 排冷水 → 入新水 → 加固色劑 1g/L → 升溫持溫 → 排固色水 → 加冷水洗 → 確認水無色 → 排冷水 → 出缸

### 精煉劑

- **前處理步驟（染色前使用）**
- 去除纖維或布面上的雜質，提升材料的親水性與均勻性，讓後續染色更穩定。
- 通常由**界面活性劑**組成，親油端乳化油汙，親水端吸附水帶走油汙。
- 作用：
    - 去除油脂、蠟質與天然雜質
    - 乳化油污、分散污垢
    - 改善潤濕性
    - 提高染色均勻性
    - 提高再現性減少批差
