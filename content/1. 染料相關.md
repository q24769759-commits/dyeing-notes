## 1-2 染料特性 & 上色原理

### ( 1 ) 尼龍 — 酸性染料（Acid Dye）

#### 尼龍-酸性染料染色原理

尼龍纖維末端帶胺基(–NH₂)，在酸性環境下與 H⁺ 反應帶正電：

```
尼龍–NH₂ + H⁺  ⇌  尼龍–NH₃⁺
```

酸性染料帶磺酸基(–SO₃H)，進入水中解離帶負電：

```
染料–SO₃H  ⇌  染料–SO₃⁻ + H⁺
```

正負相吸，完成上色：

```
尼龍–NH₃⁺ + 染料–SO₃⁻  ⇌  尼龍–NH₃⁺···SO₃⁻–染料
```

#### 酸性染料特性

| 項目 | 特性 |
| --- | --- |
| 染料電荷 | 陰離子型（Anionic） |
| 水溶性 | 高 |
| 適用纖維 | 尼龍、羊毛、絲 |
| 染色條件 | 酸性浴（pH 4~6） |
| 上染機制 | 離子鍵結合 |
| 耐洗牢度 | 中~優 |
| 耐光牢度 | 中~優 |
| 染色溫度 | 80~100°C |

#### 酸性染料類別

染料搭配最理想為相同類別，以避免染料特性不同在同染程條件下造成的上色異常。

| 項目 | 均染型（Levelling） | 半均染型（Half-Milling） | 固著型（Milling） |
| --- | --- | --- | --- |
| 均染性 | ★★★★★ | ★★★★ | ★★ |
| 上色速度 | 慢 | 中 | 快 |
| 色花風險 | 最低 | 低 | 高 |
| 濕牢度 | 普通 | 良好 | 最佳 |
| 配色穩定性 | 佳 | 最佳 | 較差 |

### ( 2 ) 特多龍染料 — 分散染料（Disperse Dye）

#### 特多龍-分散染料上色原理

特多龍（PET）分子鏈不含可供染料形成離子鍵的官能基，因此無法使用酸性染料染色：

```
PET ≈ 不含 -NH₂、-NH₃⁺ 等染座
```

#### 特多龍染色過程
```text
染液中的分散染料
        │
        ▼
接觸 PET 纖維表面
        │
        ▼
吸附於纖維表面
        │
        ▼
120~135℃ 高溫
PET 分子鏈鬆動
        │
        ▼
染料擴散進入纖維
        │
        ▼
冷卻降溫
PET 分子鏈收縮
        │
        ▼
染料被包埋於纖維內
        │
        ▼
完成染色
```
#### 分散染料特性

分散染料本身：
- 幾乎不溶於水
- 分子很小
- 非離子型染料

在水中狀態：

```
染料微粒  →  分散劑包覆  →  均勻懸浮於染液中
```

- **不溶於水**，以微粒狀態進入纖維
- 需要高溫高壓染色
- 不需要像尼龍那樣嚴格控制上色速度
- 非化學鍵結，而是**擴散進入纖維**

## 1-3 單色試驗

目的：了解單支染料在不同溫度下的上染率（吸盡率）與色光變化，確認染料的相容性。

### 如何解讀上色曲線

- **曲線陡峭的溫度區間** = 染料快速上色區（高風險，色花易發生在此）
- 此區間越窄 → 升溫速率要越慢（見 3. 染程相關）

```
紅單色實驗 ──┐
黃單色實驗 ──┼── 比對三支染料的上色溫度區間
藍單色實驗 ──┘
            │
            ▼
    上色區間是否接近？
            │
    ┌───────┴───────┐
   是               否
    │               │
可用同一升溫程序   分析差異大的那支
直接組合試染       ↓
                是否能換染料？
                ┌──┴──┐
               能      不能
                │       │
              換掉    設計分段升溫
                       程序後再試
```

## 1-4 階段性上色

目的：設計兩階段試驗，使染料在同配方助劑條件，不同溫度下上色，以觀察單支染料在該條件下的上染率（吸盡率）與色光變化，評估染料的相容性。

### 作法

#### 第一階段

染程設計初始升溫至30°C後保溫10分鐘，後續每10°C一階以1°C/min速率升溫並保溫10min，每20分鐘出一片色樣並保留殘液，殘液留做第二階段(殘液)試驗。

![[Pasted image 20260604145752.png|611]]

#### 第二階段 — 殘液吸收

第一階段出缸後布樣取出，並另外取一片新布樣放入殘液鋼杯跑第二階段染程做殘液吸收。

![[Pasted image 20260604155035.png|609]]

### 範例：以 R.2B 為例

配方濃度 R.2B：0.2%，助劑：SER 1%、PHS 0.3 g/L  
布樣：102B 15g，水：255g

試驗結束將同溫度的兩階段色樣測色並左右對照貼樣，整理成下圖報告。

由報告可以看出 R.2B 在 0.2% 濃度下 60–70°C 間為染料上色關鍵溫度，且在該溫度區間下染料幾乎已完全吸盡，因此在染程設計上 70°C 以前的升溫需放緩並拉長持溫時間，尤其在 60–70°C 間。

## 1-5 新染料評估事項

### QC 核心評估項目

#### ( 1 ) 環保法規合規

- 指定負責人追蹤 Oekotex、REACH、客戶需求 等更新
- 每次法規更新 → 發文要求相關供應商提供對應合規文件
- 新限用物質出現 → 現有在用染料也要回顧確認
- 建立並維護內部限用物質對照表，新染料入廠前對照確認

#### ( 2 ) 同步上色性

- 紅、黃、藍分別做[[1. 染料相關#1-3 單色試驗\|單色試驗]]，記錄各溫度階段的上色速率
- 比對三支染料的上色時間點是否接近
- 時間接近 → 可用同一升溫程序同步控制，色花風險低
- 時間差異大 → 色花風險高，需換染料或分段調整（見 3. 染程相關）

#### ( 3 ) 移染性（均染劑選用的影響）

- 移染性高的染料：對均染劑依賴度低，但浴比波動影響較大
- 移染性低的染料：必須搭配均染劑，助劑選型需配套評估（見 [[2. 助劑相關]]）

#### ( 4 )正反面色差、邊縫、勾毛深淺（2-tone 問題）

- 新染料入廠前需做正反面色差測試，DE(CMC) 標準同 [[4. 對色原則]]
- 勾毛深淺需目視確認，2-tone 明顯者不予採用

#### ( 5 )牢度

| 牢度類型     | 測試標準        | 最低合格等級 | 備註       |
| -------- | ----------- | ------ | -------- |
| 水洗牢度（變色） | ISO 105-C06 | 4      | —        |
| 水洗牢度（沾色） | ISO 105-C06 | 4      | —        |
| 日曬牢度     | ISO 105-B02 | 4      | —        |
| 乾摩擦牢度    | ISO 105-X12 | 4      | —        |
| 濕摩擦牢度    | ISO 105-X12 | 4      | 深色染料尤其注意 |

#### ( 6 )光源差

- 燈箱切換 D65/TL84/A 光源，色差盡量小
- 有明顯跳燈現象的染料，須在樣品確認時同步告知客戶

#### ( 7 ) 新染料替代難度

- 與 Dyestar 舊染料的升溫程序差異
- PFAS 替換狀況（是否影響牢度或操作條件）
- 客戶是否需要書面同意換料

#### ( 8 ) 採購相關

- 染料單價比較
- 配方耗用成本比較
- 最低採購量
