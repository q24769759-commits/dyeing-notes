## 1-2 染料特性 & 上色原理

### ( 1 ) 尼龍 — 酸性染料（Acid Dye）

#### 尼龍-酸性染料染色原理

尼龍纖維末端帶胺基(–NH₂)，在酸性環境下與 H⁺ 反應帶正電：

```
尼龍–NH₂ + H⁺  ⇌  尼龍–NH₃⁺
```

酸性染料帶磺酸基(–SO₃H)，進入水中解離帶負電：

```
染料–SO₃H  ⇌  染料–SO₃⁻ + H⁺
```

正負相吸，完成上色：

```
尼龍–NH₃⁺ + 染料–SO₃⁻  ⇌  尼龍–NH₃⁺···SO₃⁻–染料
```

#### 酸性染料特性

| 項目 | 特性 |
| --- | --- |
| 染料電荷 | 陰離子型（Anionic） |
| 水溶性 | 高 |
| 適用纖維 | 尼龍、羊毛、絲 |
| 染色條件 | 酸性浴（pH 4~6） |
| 上染機制 | 離子鍵結合 |
| 耐洗牢度 | 中~優 |
| 耐光牢度 | 中~優 |
| 染色溫度 | 80~100°C |

#### 酸性染料類別

染料搭配最理想為相同類別，避免染料特性不同在同染程條件下造成的上色不同調。

| 項目    | 均染型（Levelling） | 半均染型（Half-Milling） | 固著型（Milling） |
| ----- | -------------- | ------------------ | ------------ |
| 均染性   | ★★★★★          | ★★★★               | ★★           |
| 上色速度  | 慢              | 中                  | 快            |
| 色花風險  | 最低             | 低                  | 高            |
| 濕牢度   | 普通             | 良好                 | 最佳           |
| 配色穩定性 | 佳              | 最佳                 | 較差           |

### ( 2 ) 特多龍染料 — 分散染料（Disperse Dye）

#### 特多龍-分散染料上色原理

特多龍（PET）分子鏈不含可供染料形成離子鍵的官能基，因此無法使用酸性染料染色：

```
PET ≈ 不含 -NH₂、-NH₃⁺ 等染座
```

#### 特多龍染色過程
```text
染液中的分散染料
        │
        ▼
接觸 PET 纖維表面
        │
        ▼
吸附於纖維表面
        │
        ▼
120~135℃ 高溫
PET 分子鏈鬆動
        │
        ▼
染料擴散進入纖維
        │
        ▼
冷卻降溫
PET 分子鏈收縮
        │
        ▼
染料被包埋於纖維內
        │
        ▼
完成染色
```
#### 分散染料特性

分散染料本身：
- 幾乎不溶於水
- 分子很小
- 非離子型染料

在水中狀態：

```
染料微粒  →  均勻懸浮於染液中
```

- **不溶於水**，以微粒狀態進入纖維
- 需要高溫高壓染色
- 不需要像尼龍那樣嚴格控制上色速度
- 非化學鍵結，而是**擴散進入纖維**

## 1-4 階段性上色

目的：設計兩階段試驗，使染料在同配方助劑條件，不同溫度下上色，以觀察單支染料在該條件下的上染率（吸盡率）與色光變化，評估染料的相容性。

### 作法

#### 第一階段

染程設計初始升溫至30°C後保溫10分鐘，後續每10°C一階以1°C/min速率升溫並保溫10min，每20分鐘出一片色樣並保留殘液，殘液留做第二階段(殘液)試驗。

![[Pasted image 20260613075215.png|671]]

#### 第二階段 — 殘液吸收

第一階段出缸後布樣取出，並另外取一片新布樣放入殘液鋼杯並加0.3g/L HAC跑第二階段染程做殘液吸收。

![[Pasted image 20260613075926.png|663]]

### 範例：以 R.2B 為例

配方濃度 R.2B：0.2%，助劑：SER 1%、PHS 0.3 g/L  
布樣：102B 15g，水：255g

試驗結束將同溫度的兩階段色樣測色並左右對照貼樣，整理成下圖報告。

由報告可以看出 R.2B 在 0.2% 濃度下 60–70°C 間為染料上色關鍵溫度，且在該溫度區間下染料幾乎已完全吸盡，因此在染程設計上 70°C 以前的升溫需放緩並拉長持溫時間，尤其在 60–70°C 間。

## 1-5 新染料評估事項

### QC 核心評估項目

- **染料成分符合法規要求**
- **染料基本特性確認**（單色試驗、階段升溫試驗）
- **染程相容性評估**（上色區間、同染程試染）
- **色光一致性評估**（Two Tone、跳燈）
- **量產適用性評估**（色花、助劑調整）
- **成本計算評估**

#### ( 1 ) 環保法規合規

- 指定負責人追蹤 Oekotex、REACH、客戶需求 等更新
- 每次法規更新 → 發文要求相關供應商提供對應合規文件
- 新限用物質出現 → 現有在用染料也要回顧確認
- 建立並維護內部限用物質對照表，新染料入廠前對照確認

#### ( 2 ) 染料組合特性

- 紅、黃、藍分別做[[1. 染料相關#1-3 單色試驗\|單色試驗]] & 階段升溫，確認染料特性 & 設計染程升溫曲線
- 比對三支染料的上色時間點是否接近
- 時間接近 → 可用同一升溫程序同步控制，色花風險低
- 時間差異大 → 色花風險高，需換染料或分段調整
```
紅 階段升溫實驗 ──┐
黃 階段升溫實驗 ──┼── 比對三支染料的上色溫度區間
藍 階段升溫實驗 ──┘
            │
            ▼
    上色區間是否接近？
            │
    ┌───────┴───────┐
   是               否
    │               │
可用同一升溫程序   分析差異大的那支
組合試染             ↓
                是否能換染料？
                 ┌──┴──┐
                能    不能
                 │     │
               換掉    組合不適用
```

#### ( 3 )確認染料組合是否跳燈(在不同燈光下的色光差異)

- 新染料試打色060 卡其、070灰、140綠，跟舊染料對比日光燈下目視顏色相近，再到對色燈箱用D65、A光源以及到窗邊日光下確認是否有在不同光源下色光明顯差異的狀況

#### ( 4 )正反面色差、邊縫、勾毛深淺（two-tone 問題）
  - 試染070灰色，確認色樣是否有底跟面色差，帶縫帶面深淺對比與色光差異，如果出現帶背或邊縫顏色特別深或明顯偏單一色光(底偏紅)，即是有two-tone 問題，可試驗換助劑或助劑用量調整是否有改善，若無改善則染料組合不適用

#### ( 5 )牢度
試染深色120、190，確認各項牢度是否符合廠內標準，評估染料在高濃度染色下牢度狀況，適用的固色配方&流程
