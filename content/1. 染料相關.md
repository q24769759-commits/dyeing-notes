## 1. 尼龍用染料 — 酸性染料（Acid Dye）

### (1.1) 尼龍染色原理

尼龍纖維末端帶胺基(–NH₂)，在酸性環境下與 H⁺ 反應帶正電：

```
尼龍–NH₂ + H⁺  ⇌  尼龍–NH₃⁺
```

酸性染料帶磺酸基(–SO₃H)，進入水中解離帶負電：

```
染料–SO₃H  ⇌  染料–SO₃⁻ + H⁺
```

正負相吸，完成上色：

```
尼龍–NH₃⁺ + 染料–SO₃⁻  ⇌  尼龍–NH₃⁺···SO₃⁻–染料
```

### (1.2) 酸性染料特性

- 水溶性陰離子染料
- 靠**離子鍵**吸附在尼龍纖維上
- 染色溫度約 95–100°C
- 顏色鮮豔、色譜齊全、螢光色選擇多

### (1.3) 酸性染料類別

| 項目    | 均染型（Levelling） | 半均染型（Half-Milling） | 固著型（Milling） |
| ----- | -------------- | ------------------ | ------------ |
| 均染性   | ★★★★★          | ★★★★               | ★★           |
| 上色速度  | 慢              | 中                  | 快            |
| 色花風險  | 最低             | 低                  | 高            |
| 濕牢度   | 普通             | 良好                 | 最佳           |
| 配色穩定性 | 佳              | 最佳                 | 較差           |

### (1.4) 染料選擇考量

- 配色相容性
- 上色速度一致性
- 均染性
- 色光穩定性
- 量產再現性

## 2. 特多龍（PET）用染料 — 分散染料（Disperse Dye）

### (2.1) 特多龍（PET）特性

PET 分子結構：[-O-CH₂-CH₂-O-CO-C₆H₄-CO-]n

- 幾乎沒有離子基團
- 沒有 -NH₂、-COOH 等可與染料形成鍵結的官能基
- 高結晶度
- 疏水性強
- 吸水率只有約 0.4%
### (2.2) 分散染料特性

分散染料本身：
- 幾乎不溶於水
- 分子很小
- 非離子型染料

在水中狀態：

```
染料微粒  →  分散劑包覆  →  均勻懸浮於染液中
```

- **不溶於水**，以微粒狀態進入纖維
- 需要高溫高壓染色
- 不需要像尼龍那樣嚴格控制上色速度
- 非化學鍵結，而是**擴散進入纖維**

染色過程

```
染液中的染料
  ↓ 接觸 PET 表面
  ↓ 吸附於表面
  ↓ 高溫使 PET 分子鬆動
  ↓ 染料擴散進入纖維
  ↓ 冷卻後被鎖在纖維內
```
## 3. 單色試驗
目的:了解單支染料在不同溫度下的上染率（吸盡率）與色光變化，確認染料的相容性。








## 4. 階段性上色
目的 : 設計兩階段試驗，使染料在同配方助劑條件，不同溫度下上色，以觀察單支染料在該條件下的上染率（吸盡率）與色光變化，評估染料的相容性。

作法: 
### 第一階段-
染程設計初始升溫至30°C後保溫10分鐘，後續每10°C一階以1°C/min速率升溫並保溫10min，每20分鐘出一片色樣並保留殘液，殘液留做第二階段(殘液)試驗。

![[Pasted image 20260604145752.png|611]]

### 第二階段-殘液吸收
第一階段出缸後布樣取出，並另外取一片新布樣放入殘液鋼杯跑第二階段染程做殘液吸收。

![[Pasted image 20260604155035.png|622]]
### 範例 : 以 R.2B 為例 
配方濃度R.2B : 0.2%, 助劑 : SER:1%, PHS : 0.3 g/L
布樣 : 102B 15g ,水 : 255g 
試驗結束將同溫度的兩階段色樣測色並左右對照貼樣，整理成下圖報告
由報告可以看出R.2B在0.2%濃度下60-70°C間為染料上色關鍵溫度，且在該溫度區間下染料幾乎已完全吸盡，因此在染程的設計上70度以前的升溫需放緩並拉長持溫時間尤其在60-70°C間。
