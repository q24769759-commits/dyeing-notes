### 5-1 軟水

水的硬度主要來自：
- 鈣離子（Ca²⁺）
- 鎂離子（Mg²⁺）
##### 水硬度等級

雖然實際存在的是 Ca²⁺、Mg²⁺，但為了統一計算，水處理業習慣換算成：

CaCO₃ mg/L (ppm)

| 硬度 (ppm) | 等級   |
| -------- | ---- |
| 0~60     | 軟水   |
| 61~120   | 中等硬度 |
| 121~180  | 硬水   |
| ＞180     | 極硬水  |

染整業通常要求：**總硬度 (鈣硬度 + 鎂硬度) ≤ 20 ppm**

##### 軟水製造- 離子交換法

樹脂上的鈉離子（Na⁺）與鈣鎂離子交換：

Ca²⁺ + 2Na-R → Ca-R₂ + 2Na⁺

Mg²⁺ + 2Na-R → Mg-R₂ + 2Na⁺

 樹酯再生

當樹脂吸附太多Ca、Mg後需再生，排出廢液後恢復軟化能力。

使用： 工業鹽（NaCl）

反應：

Ca-R₂ + 2NaCl → 2Na-R + CaCl₂

Mg-R₂ + 2NaCl → 2Na-R + MgCl₂


##### 軟水對染色的優點

避免：
- 鈣離子與染料聚集
- 色花
- 染料沉澱

提升：
- 均染性
- 再現性
- 色光穩定性
