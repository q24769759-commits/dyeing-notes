# 單色實驗

← [[0. 染色相關項目|索引]]

---

## 操作步驟

1. 按浴比配製染浴（染料、水、酸劑、均染劑）
2. 從常溫開始升溫，設定每 10°C 取樣一次殘液
3. 各溫度取樣後測量殘液吸光度（或用比色卡目視）
4. 計算各溫度階段的上色率（%）

## 如何解讀上色曲線

- **曲線陡峭的溫度區間** = 染料快速上色區（高風險，色花易發生在此）
- 此區間越窄 → 升溫速率要越慢（見 [[染程設計重點]]）
